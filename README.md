# Task 2: Operating System Security Fundamentals

## Objective
To understand OS-level security concepts and basic system hardening techniques in Linux.

## Tools Used
- Ubuntu Linux (Virtual Machine)
- UFW Firewall
- Linux Terminal Commands

## Tasks Performed
- Explored user accounts and permissions
- Learned Linux file permissions (chmod, chown)
- Compared root and normal users
- Enabled and configured firewall (UFW)
- Identified running processes and services
- Disabled unnecessary services
- Documented OS hardening best practices

## Outcome
This task helped me understand how operating system security works at a fundamental level and how proper configurations reduce system attack surface.
